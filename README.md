# Ravann

Ravann is an ad-free music player for Android.

**Ravann is invite-only.** You need an invite code from the person who shared Ravann with you. Without a code, the app won't open.

This page only holds the app's install files. The app checks it once a day and updates itself.

## How to install

1. Open **Releases** on the right and pick the newest version.
2. Download the `.apk` file under **Assets**.
3. Open it on your Android phone. The first time, Android asks you to allow installing from this source: allow it.
4. Open Ravann and type your **invite code** (like `SAM-4821`). You only do this once per phone.
5. Sign in with your Google account.

New versions install by themselves while you're not using Ravann (you can turn this off in Settings › About Ravann). Your music, downloads and settings stay.
