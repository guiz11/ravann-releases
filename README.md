# Ravann

Ravann is an ad-free music player for Android.

This page only holds the app's install files. The app checks it once a day and offers new versions by itself.

## How to install

1. Open **Releases** on the right and pick the newest version.
2. Download the `.apk` file under **Assets**.
3. Open it on your Android phone. The first time, Android asks you to allow installing from this source: allow it.
4. Open Ravann and sign in with your Google account.

Later updates show up inside the app on Home. Tap **Update** and Android installs the new version over the old one; your music and settings stay.
